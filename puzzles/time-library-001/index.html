Chronicles of the Time Library

The Paradox of the Missing Tome

The Chrono-Librarian's Oath

Welcome, esteemed Chrono-Librarian. Our sacred Time Library, repository of all historical knowledge, faces a grave threat. A critical tome, detailing a pivotal moment in history, has been misplaced, creating a dangerous paradox that ripples through the timelines. It is your solemn duty to restore order.

Using the fragmented clues left behind, you must deduce which Librarian, from which Era, and using which Temporal Device, inadvertently caused this temporal anomaly. The fate of history rests in your hands.

Quick Start Guide

  • 1. Navigate the three logic grids: Librarian ↔ Era, Librarian ↔ Device, and Era ↔ Device.
  • 2. Each cell represents a possible connection between the row and column entities.
  • 3. Click a cell to cycle its state: ✔ TRUE (confirmed match) → ✖ FALSE (ruled out) → UNKNOWN (neutral).
  • 4. Use the clues to logically deduce the TRUE and FALSE connections.
  • 5. Hover over a clue to highlight related entities in the grids.
  • 6. Hover over a cell to highlight its corresponding row and column headers.
